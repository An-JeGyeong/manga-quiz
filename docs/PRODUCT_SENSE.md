# 프로덕트 센스

## 이 서비스가 존재하는 이유
단순 만화 추천이 아니라 "내 manga 취향이 뭔지 알고 싶다"는 욕구를 자극.
MBTI·연애 테스트처럼 결과를 공유하고 싶어지는 구조가 핵심.

## 타깃 유저
- 일본 만화를 좋아하지만 뭘 읽을지 모르는 20대
- 취향 테스트·심리 테스트를 즐기는 토스 유저
- 친구와 취향 비교를 즐기는 유저

## 바이럴 설계
- 결과 타입명이 구체적이고 과장될수록 공유율 높음
  - 나쁜 예: "액션 팬"
  - 좋은 예: "먼치킨 세계관에 중독된 현실 도피러"
- 결과 카드에 수치 스탯이 보이면 "내 취향 스탯"처럼 느껴져 캡처 욕구 자극
- "친구랑 취향 비교하기" CTA가 단순 공유보다 전환율 2~3배 높음

## 망가 플랫폼 연계 (4단계 목표)
- 추천 작품 클릭 → 망가 플랫폼(추후 런칭) 상세 페이지로 연결
- 취향 테스트 결과 → 플랫폼 구독 시 개인화 추천에 활용
- 신작 출시 시 취향 타입 기반 사전예약 유입 채널로 사용

## 수익화 구조 (MVP 단계)
- 앱인토스 인앱 광고 SDK 연동 (결과 페이지 하단)
- 추후: 망가 플랫폼 구독 전환 쿠폰 발급

## Codex 버그 탐지 프롬프트
새 기능 완성 후 Codex에게 이 프롬프트를 사용:

```
다음 파일을 읽고 버그를 찾아줘.

검사 항목:
1. TypeScript 타입 불일치
2. 점수 계산 엣지케이스
   - 세 축이 모두 0일 때 타입 결정
   - 질문 건너뛰기 후 scores 누락 여부
3. 앱인토스 WebView 금지 API 사용
   - router.back() / window.open() / localStorage / sessionStorage
4. undefined/null 미처리
5. 컴포넌트 props 타입 누락

출력 형식:
파일명 | 라인 번호 | 버그 내용 | 수정 제안
```
